# quantity-amount-calculator
The Quantity Amount Calculator is a simple and responsive web tool designed using HTML and Bootstrap. It allows users to input a quantity and a unit price, then calculates the total amount instantly.The interface is clean and mobile-friendly, thanks to Bootstrap’s grid system and form controls.

Key Features:

1] User Inputs: Two input fields – one for quantity and one for price per unit.

2] Real-Time Calculation: Calculates total amount automatically using JavaScript when the user enters values.

3] Responsive Design: Built with Bootstrap 5 to ensure optimal display on all devices.

4] Clear Layout: Uses Bootstrap cards and form groups for a neat, organized appearance.

This calculator is ideal for small businesses, ecommerce platforms, billing systems, or any web-based application that needs simple price calculations based on quantity.
